# NearChat Lab

Технический прототип локального текстового чата для iPhone. Целевая платформа MVP — iOS 26; текущие локальные deployment targets: ядро 18.0, приложение 18.6. Без аккаунтов, внешних серверов и аналитики. Noise включён в исходники под MIT; сборка использует системный CryptoKit без загрузки сетевых зависимостей.

## Что можно проверить

- Обнаружение и TCP-обмен через общую Wi-Fi/LAN-сеть (Bonjour + Network framework), без Bluetooth и интернета.
- Обнаружение и обмен по Bluetooth LE: каждый iPhone одновременно поддерживает роли central и peripheral.
- Логическое обнаружение участников и зашифрованную пересылку А↔Б↔В, в том числе через разные транспорты.
- Личные сообщения, отправку текста всем обнаруженным участникам отдельными зашифрованными конвертами, подтверждения конечного получателя, исчезновение участников и потерю маршрута.
- Диагностику связей, числа переходов, пересылок и дубликатов; исключение прямой связи для воспроизводимого теста mesh.

Добавлены сохраняемые очереди отправки и ретрансляции на 24 часа, история с FIFO, квитанции приёма/прочтения и ограниченный режим памяти при ошибке записи. Закрытые группы поддерживают приглашения и отмену вступления, обмен через mesh, текстовую историю, индивидуальные лимиты и управление составом. Полные правила общего канала ещё не реализованы. Добавлены ручная сверка ключей и forward secrecy новых текстовых конвертов. Требования MVP сохраняются; приложение пока реализует исследовательский срез, а не весь продукт.

Хранение, передача, квоты, непрочитанные, личное согласие и закрытые группы прошли полный набор из 185 тестов ядра, включая жизненный цикл установки и подтверждаемую очистку при нехватке места. Приложение для iPhone собирается. Предыдущая версия с индикатором была подписана и проверена на устройстве; новый срез запросов на устройствах пока не проверен. На подключённом iPhone проверены запуск и сохранность 8 записей истории; тестовый узел Mac получил квитанции доставки и прочтения через LAN. Пользователь также подтвердил Bluetooth и Wi-Fi. UI-автотесты не выполнялись по выбору пользователя; детали и ограничения — в отчёте устройств. История читается страницами по 200; начальные бюджеты — 100 МБ для собственной переписки и 5 МБ для ретрансляции. В разделе «Настройки» доступны изменение квот, расчёт и подтверждение очистки. Удаление переписок остаётся будущей возможностью. Подробности: [Хранение и передача](docs/prototype/STORAGE-TRANSFER.md), [Настройки квот](docs/prototype/QUOTA-SETTINGS.md).

На экране «Чаты» доступны отдельные диалоги и группы, создание группы и входящие запросы/приглашения; управление открывается через сведения о чате. Работают лимит до 32, выход/исключение, разрешённый возврат и отмена ожидающего вступления. [Сценарии и границы](docs/prototype/GROUP-MVP.md). В симуляторе проверены создание, лимит и завершение; на физический iPhone новая сборка пока не устанавливается.

После полной переустановки создаётся новая локальная идентичность; обновление старой установки сохраняет ключ и историю. При нехватке места предлагается подтверждаемая очистка старейших сообщений без изменения квоты. [Поведение и проверки](docs/prototype/INSTALLATION-AND-DISK-SPACE.md).

Локальная проверка безопасности и устойчивости завершена 2026-11-27: исправлены некорректные и устаревшие объявления, добавлены общие лимиты входа, проверены повреждённые конверты/архив и восстановление после SIGKILL писателя. Отдельный ASAN harness и статический анализ VFS прошли. Ручная сверка ключей и forward secrecy добавлены следующим срезом; защита от Sybil и испытания на устройствах остаются открытыми. [Отчёт и воспроизведение](docs/prototype/SECURITY-REVIEW.md).

Проверка собеседника открывается через **«О чате → Проверить ключи»**: сравните полный код на обоих устройствах лично или по уже доверенному каналу. Для новых текстов используется Noise IK со сменой ключа после каждого пакета. При отсутствии канала сообщение ждёт в локальной зашифрованной очереди. Все участники нового обмена и ретрансляторы должны поддерживать новый формат; прежняя история сохраняется. [Поведение, обновление и границы FS](docs/prototype/VERIFIED-FORWARD-SECRECY.md).

## Запуск на iPhone

1. Открыть [NearChat.xcodeproj](NearChat.xcodeproj) в Xcode 26 или новее.
2. Выбрать target **NearChat**, вкладку **Signing & Capabilities**, свой **Team** и при необходимости уникальный Bundle Identifier. Платная команда не является условием сборки исходников; фактическое provisioning зависит от выбранного аккаунта и устройств.
3. Выбрать подключённый iPhone с iOS не ниже текущего deployment target 18.6, при необходимости включить Developer Mode и запустить приложение. Для проверки mesh нужны три физических iPhone.
4. Обновить приложение на всех участвующих устройствах: новые защищённые конверты v3 требуют обновлённых конечных устройств и ретрансляторов. На каждом задать различимое имя (А, Б, В), включить нужные способы связи и нажать **Включить**.
5. Разрешить Bluetooth и локальную сеть. Для теста LAN устройства должны иметь возможность общаться между собой: гостевая сеть с изоляцией клиентов может блокировать обмен.

Счётчик проверен пользователем на устройстве. У нижней иконки **Чаты** показывается красный счётчик непрочитанных входящих (до 99, далее «99+»). Он сохраняется после перезапуска и уменьшается при фактическом прочтении.

Отправка на экране выбранного диалога в разделе **Чаты**. Переписка открывается у последнего сообщения, история загружается страницами именно этого чата. Список показывает превью и непрочитанные, черновики разделены между диалогами. [UX и проверки](docs/prototype/UX.md). Для личного текста сначала нужен запрос и согласие; два отказа включают паузу на 24 часа. Есть ручная блокировка. Обновите все участвующие клиенты для поддержки запросов; [детали и ограничения](docs/prototype/DIRECT-CONTACTS.md).

## Проверки

```sh
swift test
xcodebuild -project NearChat.xcodeproj -scheme NearChat \
  -configuration Debug -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
xcodebuild -project NearChat.xcodeproj -scheme NearChat \
  -configuration Debug -destination 'generic/platform=iOS' \
  -derivedDataPath DerivedData CODE_SIGNING_ALLOWED=NO build
```

Для ограниченного окружения кеши SwiftPM можно перенести внутрь проекта:

```sh
env CLANG_MODULE_CACHE_PATH="$PWD/.build/ModuleCache" \
  SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/ModuleCache" \
  swift test --scratch-path .build --disable-sandbox
```

Сборка без подписи проверяет компиляцию, но не устанавливается на физический iPhone. Симулятор тоже нужно локально подписывать для проверки Keychain: например, использовать `CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=-` при сборке для выбранного симулятора. Симулятор не подтверждает работоспособность BLE и фоновой радиосвязи.

## Устройство проекта

- `Sources/NearChatCore` — протокол, CryptoKit-конверты, транзакционная история и очереди, mesh, подтверждения, framing.
- `Sources/BoundedSQLite` — VFS-обёртка системного SQLite, ограничивающая рост файлов вместе с живым журналом.
- `Tests/NearChatCoreTests` — детерминированные проверки поведения mesh и повреждённых пакетов.
- `NearChat/Transport` — реальные адаптеры BLE и LAN; все callbacks обрабатываются на main queue.
- `NearChat/App` — SwiftUI-интерфейс, управление сеансом, Keychain и диагностика.
- `docs/prototype/PROTOTYPE.md` — допущения, ограничения и результаты проверок.
- `docs/prototype/DEVICE-TESTS.md` — ручной сценарий на трёх iPhone и таблица результатов.

Xcode-проект уже сохранён. Core подключён как локальный Swift Package: новые файлы ядра и C-target подхватываются пакетом, пересоздание проекта для них не требуется. Локальные настройки signing и deployment target сохранены.
