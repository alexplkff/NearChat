Полная матрица LAB-01–LAB-14 пока не выполнена в точно описанных условиях. Записывать модель устройств, версию iOS, build, время, число links, hops, счётчики и наблюдаемый результат. Ожидаемый результат — цель эксперимента прототипа, не утверждённая гарантия MVP.

## Подготовка

Установить проект из Xcode на три iPhone с iOS 26+, назвать А, Б, В. Сверить fingerprints на экранах. Разрешить Bluetooth и Local Network. Не использовать чувствительные сообщения. Интернет для теста выключить; общую Wi-Fi-сеть оставить включённой в LAN-сценарии. Не путать отсутствие интернета с полным выключением Wi-Fi. Проверять состояние переключателей в Settings, а не полагаться на Control Center.
