# Отмена вступления и позднее подтверждение

Статус: одноразовый макет для обсуждения, не реализация iOS и не подтверждение корректности протокола.

Вопрос: остаётся ли группа неактивной после отмены, если создатель уже оформил вступление, а его ответ задержался? Понятна ли разница между локальной отменой и освобождением места у создателя?

[Открыть самостоятельный HTML](group-join-race.prototype.html). Файл открывается в браузере без установки, сервера и внешних ресурсов. Вкладки предлагают пошаговые сценарии; свободные кнопки позволяют менять порядок событий.

## Что показывает макет

| Событие | У пользователя | У создателя |
| --- | --- | --- |
| Согласие отправлено | Ожидание подтверждения | Запрос ещё не обработан |
| Создатель оформил вступление | Ожидание ответа | Место занято |
| Пользователь отменил до получения ответа | Отмена ожидает подтверждения; группа не активируется | Место может оставаться занятым |
| Старый ответ пришёл после отмены | Не активирует группу | Сам ответ не освобождает место |
| Отмена дошла до создателя | Ожидание подтверждения обработки | Запрос отозван либо выполнен выход; место свободно |
| Подтверждение отмены дошло | Вступление отменено | Результат уже применён |

Варианты: обычное вступление; отмена до обработки; отмена после фиксации; задержка самой отмены; повторные ответы. Повтор той же попытки не занимает дополнительное место.

## Границы

- Правило отмены согласовано в REQ-098. Формулировки «Отмена ожидает подтверждения» и «Вступление отменено» подтверждены пользователем в REQ-099; это не подтверждение всей технической модели.
- Условные 5 исходных участников иллюстрируют счётчик. Продуктовый предел — индивидуальный лимит группы до 32, по умолчанию 32.
- Модель содержит одну попытку и явные события доставки. Время, истечение сроков, повторное вступление, изменение лимита, исключение и завершение группы в этом макете не разыгрываются.
- Состояние страницы хранится только в RAM. Нет реальных сетевых запросов, надёжной записи, криптографии или доступа к данным приложения.
- Автоматический прогон сценариев, сборки и тесты iOS не выполнялись. Статическая проверка файла не доказывает поведение приложения.

## Открытая техническая работа

Нужны идентификаторы попыток и периодов членства, сохраняемое намерение отмены, упорядочивание фиксации/отмены, восстановление после сбоя и повторная сверка с создателем. Нельзя удалять всю информацию об отмене так, чтобы старое подтверждение снова активировало группу. Сроки, квоты служебных записей и недоставленный выход требуют полной модели; этот макет её не заменяет.
