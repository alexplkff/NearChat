# Идентичность привязана к данным установки

2026-11-26. Для REQ-050 выбран локальный маркер, указывающий на отдельный случайный Keychain-account каждой новой установки. Один общий account без маркера не различал обновление и повторную установку; удаление общего ключа при первом запуске могло бы лишить старую установку её истории.

Существующие архивы/профиль позволяют перенести ссылку на старый `device` без замены ключа после проверки архива. Для новой установки сначала синхронизируется маркер выбранного account, затем создаются ключи и закрепляется публичный ID: прерывание между шагами не вращает идентичность на каждом запуске. Маркер исключён из backup, секреты остаются в Keychain ThisDeviceOnly. Неповреждённая старая установка может продолжить использовать проверенный legacy-ключ при отказе записи маркера и повторить миграцию позже. Повреждённый маркер или неизвестный ключ не разрешают пересоздать архив.
