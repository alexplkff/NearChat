## Референс Bitchat

Пользователь предложил https://github.com/permissionlesstech/bitchat как референс, а не как утверждённую спецификацию или базу кода. 2026-11-25 изучены README и WHITEPAPER текущей ветки main; ссылки изменяемые, commit не зафиксирован.

- [README](https://github.com/permissionlesstech/bitchat/blob/main/README.md): Bluetooth LE mesh с ретрансляцией через устройства участников; отдельный интернет-транспорт Nostr; публичное общение и личные сообщения.
- [WHITEPAPER](https://github.com/permissionlesstech/bitchat/blob/main/WHITEPAPER.md): механизмы временного хранения и передачи сообщений; Nostr-реле хранят приватные конверты; устойчивые ключи идентичности допускают связывание присутствия устройства между сеансами.
- Вывод для проектирования: отсутствие центрального сервера не означает отсутствия серверного хранения; отсутствие регистрации не означает несвязываемую анонимность. Эти свойства нельзя переносить в требования без отдельного решения.
- Wi-Fi-транспорт для нашего приложения и ограничения iOS пока не исследованы. README и whitepaper референса не являются проверкой его кода или гарантий безопасности.

- Последствие: выбор определит предметную модель чатов, приглашения и список разговоров.

### D-006 — Mesh с зашифрованной ретрансляцией

- Статус: accepted; review_required: false. Заменяет D-005.
- Источник: «каждый пользователь приложения — так же ретранслятор зашифрованных сообщений», 2026-11-25.
- Каноническое требование: REQ-008. Если А видит Б, а Б видит В, цель поведения — логическая достижимость А и В через Б при действующем пути.
- Пользователь назвал изменение Q3, но содержание меняет ограничение Q4 о прямой связи; серверные зависимости не разрешены и Q3 сохраняется.
- Зависимости: D-001, D-004.
- Влияние: пересмотрены исследования транспорта, правила состава общего чата и групп, доставка, приватность, лимиты и критерии приёмки. Протокол ретрансляции, TTL, хранение и фоновая доступность остаются открытыми; они не были приняты ранее, поэтому принятых зависимых решений для повторного подтверждения нет.
